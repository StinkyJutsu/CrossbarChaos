# Crossbar Chaos

Randomize your Rocket League crossbar sounds.

Crossbar Chaos is a free Windows application that uses the official Rocket League Stats API to detect crossbar hits and play randomized custom sounds.

## Features
- Supports Steam and Epic Games versions of Rocket League
- Custom MP3 and WAV sound library
- Session-based shuffle bag for randomized playback
- Impact-based volume adjustment
- Individual volume controls for each sound
- Selectable Windows audio output device
- Saved sound library and preferences
- Automatic Stats API configuration and restoration

## How to Use
1. Open Crossbar Chaos before launching Rocket League.
2. Add your own MP3 or WAV sound files.
3. Enable the sounds you want to use.
4. Select your preferred audio output device.
5. Enable the randomizer.
6. Launch Rocket League and play.

## Requirements
- Windows 10/11 (64-bit)
- Rocket League (Steam or Epic Games)

## Building from Source
Requires the .NET 10 SDK.

dotnet build -c Release

## Important
No sound files are included. Users must supply their own audio clips.
